# Sales Dashboard Project | Excel VBA + Interactive HTML

**Built by Faizan Zahoor – Certified Data Analyst**

Interactive sales performance dashboards built with Excel (VBA automation) and HTML, with a Power BI version in progress.

## Project Overview
This project turns raw sales data into dashboards that show performance, trends and customer insights at a glance. It includes automated Excel reporting and interactive web-based visualizations.

## What's Inside

| File | Description |
|---|---|
| `sales_dataset.xlsm` | Source sales dataset |
| `Sales_Automation project.xlsm` | Excel VBA automation for sales reporting |
| `Customer_Dashboard.xlsm` | Customer analysis dashboard |
| `Faizan_Finance_Data.xlsm` | Finance dataset and dashboard |
| `Sales Dashboard.html` | Interactive sales dashboard |
| `amazon_3d_sales_visualization.html` | 3D sales visualization |
| `cleaned_Amazon_Dashboard_DA...` | Cleaned Amazon sales data for analysis |

## Key Features
- Interactive charts linked to the data
- VBA macros that automate report building
- KPI cards: total sales, profit, top products and regions
- Cleaned, analysis-ready datasets

## Tools & Skills Used
Excel • VBA • Power BI • DAX • Data Cleaning • Dashboard Design • AI Tools

## How to Use
1. Download the `.xlsm` files and open them in Excel.
2. Click **Enable Content / Enable Macros** when prompted.
3. Open the `.html` files in any web browser to view the interactive dashboards.
